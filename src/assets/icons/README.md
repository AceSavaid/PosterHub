# Built-in science icons

These icons ship with PosterHub so they work offline. They were copied and
reduced to plain filled paths by `scripts/import-icons.mjs`; see that script
for the exact list and how to update it.

| Folder | Source | Licence |
| --- | --- | --- |
| `health/` | [Health Icons](https://healthicons.org) 3.1.0 (filled style) | CC0 1.0, public domain (see `health/LICENSE`) |
| `phosphor/` | [Phosphor Icons](https://phosphoricons.com) core 2.1.1 (duotone style) | MIT (see `phosphor/LICENSE`) |

Neither licence asks for credit on a poster. The MIT licence asks that its
notice travels with the software, which `phosphor/LICENSE` does.
